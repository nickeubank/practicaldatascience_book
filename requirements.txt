# Pinned build environment for this book.
#
# WHY EVERY VERSION IS PINNED
#
# The site is rebuilt both by hand (`jbp`) and every morning by
# .github/workflows/daily_build.yml, and both builds commit their output to
# docs/. Sphinx bakes theme markup and asset digests into every single page, so
# if the two environments disagree on even one theme package, every page in
# docs/ rewrites itself and `git pull` turns into a whole-site conflict. Only
# jupyter-book was pinned before, which left ~100 transitive packages free to
# drift: by 2026-10-28 the daily build had moved to pydata-sphinx-theme 0.17.1
# while local builds were still on 0.15.4, and the two produced different HTML
# for all ~150 pages.
#
# These versions are the ones the daily build resolved on 2026-10-28 -- i.e.
# the environment that produced the docs/ currently committed.
#
# The workflow installs from this file, so this file is the single source of
# truth. To move the build forward, bump deliberately here, rebuild, and commit
# the resulting docs/ churn in one commit of its own.
